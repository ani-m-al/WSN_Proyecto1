# WSN_Proyecto1
Sistema ROS 2 para controlar un dron DJI Tello mediante WhatsApp Cloud API. Un servidor Flask recibe mensajes y los envía a un nodo que construye y ejecuta misiones. El conector controla el dron y publica telemetría; un nodo de seguridad gestiona batería baja y otro muestra vídeo con detección básica de colores.
